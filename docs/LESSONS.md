# 実測に基づく教訓

すべて 2026 年の ROGII Wellbore Geology Prediction（$50k、6,191 チーム、コードコンペ）と、
同時期の PTCG コンペで実際に踏んだものです。推測は含めていません。

## 測定と検証

**指標の雑音床を最初に測る。** 詳細は [README](../README.md)。追う差が雑音床を超えないなら、
そのコンペでスコアを追う作業自体を打ち切る判断をする。

**in-sample の値は採用の根拠にしない。** 交差検証が魅力的な当てはめ値を4 回覆した
（左が in-sample の Δ、右が交差検証の Δ。RMSE なので負が改善。
−0.274 → +0.566 / −0.093 → +0.024 / −0.337 → +1.399 / −0.15 → +0.035）。原因は
誤差の集中で、最悪 5% の評価単位が二乗誤差の 52.5% を占めていた（本番相当の 40 件で測った
値。README の実行例は 10 件のセットで、件数が少ないと「最悪 5%」が最小 1 件に丸められて
実質 10% を指すため 42.1% と出る）。

**完璧に見える証拠が揃っていても、未接触のドロー1 点に負ける。** ある施策は leave-one-site-out
6 ブロック通過、変異試験でリーク差分ゼロ（199,746 行）、プラセボ対照つきで Δ −1.08 を示したが、
一度も触っていないデータで測り直すと −0.069 まで縮んだ。事前登録した棄却規則が提出を止めた。

**事前学習済み資産を含む検証環境は、一様にではなく選択的に壊れる。** フォーク元がマウントする
学習済みモデルが検証セットを記憶している場合、**その資産の重みを動かすノブに対してだけ**
検証環境が誤った評価を返す。同じ環境が、資産に触れないノブについては正しく評価する。
対照アーム（逆方向のノブ）を必ず用意すること。片方向だけでは「効いた」と「測定器が壊れている」を
区別できない。

**ただし「検証環境が壊れている」という結論にも裏づけが要る。** 上記の件では、リーダーボードが
検証環境と食い違ったので検証環境が誤りだと結論した。しかし private を見ると、**誤っていたのは
public の側**だった（検証環境の Δ と private の相関 +0.72 に対し、public と private は −0.51）。
**測定器が2 つあって食い違うとき、どちらが正しいかは第3の証拠なしには決まらない。**

**事前登録は勝ちを増やさない。負けを減らすだけ。** これは価値があるが、これだけでは勝てない。

## Kaggle の実務

**public スコアは測定値ではなくドローである。** ドローとは、同じ設定でも1 回ごとに違う値が
出る、抽選のような1 回分の観測を指す。 可視出力の SHA-256 が一致する2 つのノートブックが、
非公開データでの再実行で 6.470 と 6.500 に分かれた。設定の比較はファミリー平均で行う。

**公開ノートブックのタイトルの数字は再現しない。** 4 件で食い違い、しかも両方向に出た
（タイトルより良い例も悪い例もある）。作者はスコアを名前に固定したまま更新を続けるため、
保存されているコードは命名時点のコードではない。

**入力マウントのレイアウトが2 種類あり、どちらになるかは実行時まで分からない。**
`/kaggle/input/competitions/<comp>` と `/kaggle/input/<comp>` の両方を実行時に解決すること。
ハードコードすると、コンペデータ側は即死し、**事前学習資産側は `.exists()` ガードのため
エラーを出さず静かに欠落する**。後者のほうが危険。これで7 回の実行を失った。

**フォーク元が SHA を固定した検証セルを持つことがある。** ノブを1 つ変えるだけで例外を送出する。
緩めるのは例外送出だけにして、構造的な検証は残す。

**提出の一部はランタイム超過で無得点になる**（実測 8%）。最終選択の前に `error_description` を
確認する。

**コード提出の CLI は出力ファイル名の指定が必須**（`-f submission.csv`）。省くと 400 が返る。

**最終選択は Web UI からしか設定できない。** API の `SUBMISSION_GROUP_SELECTED` で読み戻して
検証するのが唯一の客観的な確認手段。

**提出枠は UTC 00:00 に回復し、採点には 10〜24 時間かかる。** 締切当日の枠は朝イチで使い切る。

> Kaggle 固有でない環境事故（自動修正ツールの暴走、稼働中サービスの扱い、依存の版）は
> `LESSONS-environment.md` にあります。テンプレート集ではリポジトリのルート、導入後は
この `docs/` に置かれます（ルート README の導入手順がコピーします）。
